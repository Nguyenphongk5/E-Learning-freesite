Giới thiệu về JavaScript

Những bước đầu với JavaScript

Đăng bởi amit ngày 15 tháng 10 năm 2022

JavaScript là ngôn ngữ kịch bản của web. Ngôn ngữ này được sử dụng trên hàng triệu trang để bổ sung chức năng, kiểm tra biểu mẫu, nhận diện trình duyệt và tạo nội dung tương tác. JavaScript hoạt động trên các trình duyệt phổ biến và là một trong những ngôn ngữ lập trình web được sử dụng rộng rãi nhất.

JavaScript được tạo ra để bổ sung tính tương tác cho trang HTML. Đây là ngôn ngữ kịch bản nhẹ, thường được nhúng trực tiếp vào trang và được trình duyệt thực thi mà không cần biên dịch trước. Java hoàn toàn khác JavaScript về cả khái niệm lẫn thiết kế; Java là một ngôn ngữ lập trình riêng.

JavaScript có thể cập nhật nội dung trang, phản hồi sự kiện như thao tác nhấn chuột, đọc và thay đổi phần tử HTML, kiểm tra dữ liệu biểu mẫu trước khi gửi lên máy chủ, cũng như nhận biết trình duyệt của người truy cập.

Biến JavaScript Biến là nơi lưu trữ thông tin, giá trị hoặc biểu thức. Tên biến có thể ngắn như x hoặc mô tả rõ hơn như carName.

Toán tử JavaScript Toán tử = dùng để gán giá trị. Toán tử + có thể cộng các giá trị và phép gán này cũng được dùng để lưu kết quả vào biến JavaScript.

Hàm JavaScript Hàm là một khối mã độc lập thực hiện một nhiệm vụ cụ thể và có thể tái sử dụng. Hàm được chạy khi có sự kiện hoặc khi được gọi. Đặt mã bên trong hàm giúp tránh thực thi ngay khi trang vừa tải. Bạn có thể gọi hàm từ nhiều vị trí trong trang hoặc từ tệp JavaScript bên ngoài. Hãy đảm bảo hàm được tải trước khi gọi.
